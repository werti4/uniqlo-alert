UNE CONFIGURATION, PUIS C’EST TOUT

Votre veille.

L’extension gère vos envies. GitHub surveille. Telegram vous prévient.

01

Connecter GitHub

Un accès limité au dépôt du projet. La connexion ChatGPT ne connecte pas automatiquement l’extension.

Jeton limité à ce dépôt : Contents : lecture et écriture, Actions : lecture et écriture. Il reste dans le stockage local de l’extension.

La même clé doit être enregistrée dans le secret GitHub UA_ENCRYPTION_KEY. Gardez-en une copie privée. La modifier rend les anciens relevés illisibles.

02

Recevoir sur iPhone

Telegram, sans abonnement.

  1. Installez Telegram et autorisez ses notifications dans les réglages de votre iPhone.
  2. Créez votre bot avec @BotFather ↗ et la commande /newbot.
  3. Ouvrez votre nouveau bot et appuyez sur Démarrer.
  4. Enregistrez TELEGRAM_BOT_TOKEN et TELEGRAM_CHAT_ID dans les secrets Actions du dépôt. Le guide du dépôt détaille comment trouver l’identifiant.
Ouvrir les secrets GitHub ↗
Les identifiants Telegram restent dans les secrets GitHub. Aucun jeton dans le code ou dans vos favoris.
03

Gérer la synchronisation

Vous contrôlez ce qui part dans le cloud.

Les ajouts et modifications restent locaux jusqu’au clic sur « Publier les favoris ». Les scans continuent même si Chrome est fermé.

Voir les exécutions ↗
Aucun relevé reçu.

Recharger remplace les modifications locales après confirmation. Exportez-les d’abord si vous souhaitez les conserver.

Ce qu’il faut savoir

  • Fréquence planifiée : 15 minutes. GitHub peut retarder ou omettre une exécution.
  • Runners standard gratuits sur dépôt public ; les données personnelles sont chiffrées.
  • 50 favoris maximum. Couleur et taille sont des souhaits. Le prix est celui de la fiche et du groupe de prix ; le stock par taille n’est pas vérifié.
  • Chaque baisse déclenche une alerte après le relevé initial, sans seuil. Un objectif de prix facultatif sert de repère.
  • En cas de blocage UNIQLO, les scans sont suspendus temporairement. Le dernier prix valide est conservé.
  • GitHub peut désactiver les tâches planifiées après 60 jours sans activité. Vérifiez périodiquement les exécutions.
